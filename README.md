# Peblo AI Workspace

An AI-powered productivity workspace built with Next.js and Tailwind CSS.

## Features

- AI Note Summaries
- Action Item Extraction
- Smart Title Suggestions
- Multi-note Workspace
- Dark / Light Mode
- Auto Save
- Responsive UI

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- Groq API
- Vercel
